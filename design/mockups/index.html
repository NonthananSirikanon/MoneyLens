Visual direction

  • Minimal & clean — ครีม/ขาว ตัวหนังสือดำ
  • ภาพวาดลายเส้นขาวดำ แบบวาดมือ
  • Calm & friendly ไม่ใช่แอปธนาคารแข็งๆ
  • Sage green เป็น accent + warm yellow เล็กน้อย
  • ตัวเลขใหญ่ อ่านเข้าใจได้ในแวบเดียว

Product principles · PROJECT.md

  • ตรวจก่อนยืนยัน — ผล OCR เป็นร่างเสมอ
  • Pipeline เดียว: กล้อง / Gallery / Share Sheet
  • ไม่ล้มเหลวเงียบ — ทุกสลิปมีสถานะให้เห็น
  • Transfer แยก ไม่นับเป็นรายรับ/รายจ่าย
  • Offline-first · ความเป็นส่วนตัวเป็นค่าเริ่มต้น

Prototype Flow

เส้นทางหลักและทางแยก — คลิกเพื่อกระโดดไปยังหน้าจอ

Onboarding → ขอสิทธิ์ → Home → Add sheet → กล้อง → ตรวจรูป → อ่านสลิป → ตรวจสอบ → บันทึกแล้ว → รายละเอียด
ทางแยกคิว → ซ้ำ เทียบรายการซ้ำ OCR ล้มเหลว → ลองใหม่/กรอกเอง เพิ่มการโอน ปฏิเสธสิทธิ์ → fallback

ทุกปุ่มหลักในหน้าจอคลิกได้ (ลิงก์ anchor) — FAB → Add sheet, แบนเนอร์ "สลิปรอตรวจ" → คิว, ปุ่มบนการ์ดในคิว → Review / Duplicate / OCR failed, bottom nav → 4 หน้าหลัก
